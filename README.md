# Omnia Ali Abdelmotleb - Personal Portfolio & Admin Dashboard

Welcome to the personal portfolio website of **Omnia Ali Abdelmotleb**, Data Analyst & Software Engineer.

## ✨ Features

- **Modern Responsive Design**: Dynamic glassmorphism & futuristic styling.
- **3D Three.js Interactive Graphics**: Interactive 3D tech torus knot and holographic data core replacing traditional static personal images.
- **Firebase Analytics & Firestore Integration**: Real-time cloud synchronization for all sections (Projects, Experience, Education, Skills, Info) with Firebase Analytics tracking visits.
- **Admin Dashboard & Cloudinary Upload**: Built-in multi-section Admin portal (`/admin`) for managing everything dynamically, with 1-click Cloudinary media uploads.
- **Projects & Filter System**: Categorized view with live demo & repository links.
